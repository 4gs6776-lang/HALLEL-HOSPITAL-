# Hallel Hospital & Maternity — Website

Rebuilt with a premium design system (medical blue / teal / mint gradient).

## Structure
```
├── index.html          Home
├── about.html           About Us
├── services.html        Services
├── doctors.html         Our Doctors
├── appointment.html     Book Appointment
├── contact.html         Contact
├── css/
│   └── style.css        All site styling
├── js/
│   └── script.js        Nav, FAQ accordion, chatbot, forms, scroll reveal
└── images/               Add your real images here (see images/README.txt)
```

## Deploy to GitHub Pages
1. Copy everything in this folder into the root of your `Hallel` repo
   (replacing the old files).
2. Add your images to `images/` using the filenames listed in
   `images/README.txt`.
3. Commit and push to `main`.
4. In the repo → Settings → Pages, confirm Source is set to the `main`
   branch, root folder.
5. Site will be live at:
   https://4gs6776-lang.github.io/Hallel/

## Forms
Contact and appointment forms post to your existing Formspree endpoint
(`xnjepoav`). No changes needed unless you want to swap it.
